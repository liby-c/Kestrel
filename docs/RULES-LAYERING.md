# 规则分层重构方案与进度

> 目的：把散落在多个文件的同类规则收敛到唯一归属层，消除「改一处漏三处」。
> 本文是重构的权威进度记录；每一步完成后更新状态。

## 一、四层模型

```
L0 宪法  constitution.md   授权、证据、产物、边界   唯一源
L1 流程  SKILL.md + flow.md  阶段、门禁、路由、账本   唯一源
L2 技能  24 个 SKILL.md    怎么做（方法/工具/判据）  只引用 L0/L1
L3 知识  references/       案例/payload/CVE/playbook  无规则
```

**归属规则**：一条规则被两个以上技能需要 → 属于 L0 或 L1；只服务一个技能 → 属于 L2。

**frontmatter 字段**：`layer` 表示技能的主要内容性质，取值 `constitution / flow / skill / knowledge`；`risk` 表示默认风险，取值 `none / low / medium / high`。两者都不使用 `L*` 记法，避免与授权等级 `L0–L4` 混淆。

`layer` 当前取值沿用重构前的技能分层（L0→`constitution`、L1→`flow`、L2→`skill`、L3→`knowledge`），表示技能的主要内容性质，**不等于文件所在层**：24 个 `SKILL.md` 在四层模型里都属于 L2 技能层，但按内容可能标为 `flow` 或 `knowledge`。
